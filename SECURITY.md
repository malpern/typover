# Security policy

Do not place credentials, private Bear note content, or a diagnostic trace that
contains writing in a public issue.

Use GitHub's **Report a vulnerability** form in the Security tab to provide a
private report. Include the Typover version, build, source revision, macOS and
Bear versions, and the smallest content-free reproduction that establishes the
problem.

The initial beta supports only the current `0.1.x` line. A report against an
older build may be closed after the behavior is checked against the latest
accepted candidate.
