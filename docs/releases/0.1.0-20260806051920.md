## What changed

- Adds the shared quiet correction-review interaction to the controlled editor
  and Bear: marks appear immediately, fade quickly, return during nearby review,
  and retain native reversible correction menus.
- Adds a shared **Always Visible** correction-mark preference.
- Fixes first-run permission routing so the next missing grant opens the exact
  Accessibility or Input Monitoring pane instead of an unrelated Settings page.
- Keeps the guarded Bear word-level integration on its safe idle-first lane.
  The lower-latency event-tap experiment remains disabled and is not a public
  preference.

## Privacy or permission changes

Bear integration requires Accessibility and Input Monitoring. Typover uses
them to verify exact Bear ranges, place reversible squiggles, and distinguish
physical word completion from pasted or programmatic text. It does not install
a helper, daemon, login item, telemetry uploader, or automatic updater.

Apple Spelling and Apple Intelligence stay on device. OpenAI or Anthropic sees
one completed sentence only after the writer explicitly selects that provider.

## Persisted-data changes and rollback compatibility

Settings remain in the `com.malpern.typover` preferences domain. Learning and
aggregate correction history remain in
`~/Library/Application Support/Typover/correction-learning.json`.

The previously qualified 0.0.9/0.1.0 update, rollback, soak, and uninstall
evidence remains applicable. This candidate adds one correction-mark preference
using the same app preferences domain and preserves the existing learning format.

## Known limitations

- Bear correction is post-pause and can safely skip when focus, selection,
  timing, text, or geometry is ambiguous.
- Bear squiggles are non-native overlays and hide when their exact anchor is
  not verifiable.
- The fast event-tap lane is research-only; its measured envelope does not
  broaden the public compatibility claim.
- The visible denied-to-allowed-to-revoked permission cycle passed on a clean
  authenticated macOS 27 session on 2026-08-08. Input Monitoring did not move
  independently of Accessibility during it, which is open separately.
- Pointer-only hover timing, Reduced Motion, VoiceOver, and the remaining Bear
  proximity/wrapped-line interaction observations are still release gates.
