## What changed

- Ships the controlled AppKit editor with immediate Apple Spelling,
  light-gray reversible annotations, local learning, contextual Apple
  Intelligence, and optional explicitly selected cloud models.
- Ships the guarded Bear word-level integration on its safe idle-first lane.
  The lower-latency event-tap experiment remains disabled and is not a public
  preference.
- Fixes a release-only sentence-boundary misclassification and adds an
  optimized pre-signing regression gate.
- Adds exact build provenance, strict archive/receipt verification, and
  adversarial rejection tests.

## Privacy or permission changes

Bear integration requires Accessibility and Input Monitoring. Typover uses
them to verify exact Bear ranges, place reversible squiggles, and distinguish
physical word completion from pasted or programmatic text. It does not install
a helper, daemon, login item, telemetry uploader, or automatic updater.

Apple Spelling and Apple Intelligence stay on device. OpenAI or Anthropic sees
one completed sentence only after the writer explicitly selects that provider.

## Persisted-data changes and rollback compatibility

Settings remain in the `com.malpern.typover` preferences domain. Learning and
aggregate correction history remain in
`~/Library/Application Support/Typover/correction-learning.json`.

A notarized `0.0.9 (20260804072932)` predecessor was installed, updated to this
candidate, restored by rollback, and updated again on a second macOS 27 Mac.
Every step left exactly one process and preserved the selected model, scope,
rewrite choice, Bear enablement, and learning-file checksum.

## Known limitations

- Bear correction is post-pause and can safely skip when focus, selection,
  timing, text, or geometry is ambiguous.
- Bear squiggles are non-native overlays and hide when their exact anchor is
  not verifiable.
- The fast event-tap lane is research-only; its measured envelope does not
  broaden the public compatibility claim.
- Final local Input Monitoring approval, exact-candidate Bear physical typing,
  and the pointer-only owned-editor Change Back rerun still require user
  presence before this artifact can be called beta-ready.
